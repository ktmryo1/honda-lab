## Adding picks

Add items to `picks.json`:

```json
{ "title": "商品名", "url": "https://...", "image": "https://...", "shop": "楽天市場", "comment": "ひとこと" }
```

## TikTok URL verification

Put the verification file downloaded from TikTok "URL properties" into the `Tiktok/` folder and push.
