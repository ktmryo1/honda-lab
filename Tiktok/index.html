Honda Lab TikTok API

動画の投稿管理ツール「AffiliateAutoPost」のTikTok連携機能

A content management tool for publishing the creator's own videos to TikTok.

概要

Honda Lab TikTok API は、個人クリエイター「ほんだ（Honda Lab）」が制作した動画を、本人が認可したTikTokアカウントへ投稿するための機能です。投稿管理ツール「AffiliateAutoPost」に組み込まれ、TikTok公式の Login Kit と Content Posting API を使用します。

主な機能と使用するスコープ

製品・スコープ用途
Login Kit / user.info.basicTikTokでログインし、連携したアカウントの表示名とアイコンを画面に表示して、どのアカウントに投稿するかを確認します。
Content Posting API / video.upload作成した動画をTikTokの下書き（受信トレイ）へアップロードし、TikTokアプリ内で編集してから投稿できるようにします。
Content Posting API / video.publishユーザーがツール上でキャプション・公開範囲・コメント等の設定を確認し、「投稿」を押した動画だけを直接投稿します。

使い方の流れ

  1. ツールの「TikTokと連携」ボタンからTikTokにログインし、権限を許可します。
  2. 連携したアカウントの表示名とアイコンが表示されます。
  3. 投稿する動画を選び、キャプション（広告の場合は「#PR」を含む）、公開範囲、コメント・デュエット・リミックスの可否、コンテンツの開示設定を確認します。
  4. 「下書きに送る」または「投稿する」を押すと、TikTokへアップロードされます。
  5. 投稿状態はツール上で確認できます。連携はいつでも解除できます。

ユーザーの確認なしに自動で投稿することはありません。ほかのユーザーの動画や個人データを収集・転載する機能はありません。

About (English)

Honda Lab TikTok API is the TikTok integration of "AffiliateAutoPost", a content management tool operated by the individual creator Honda Lab. It uses TikTok Login Kit and the Content Posting API so that the creator can upload or publish their own videos to the TikTok account they have authorized.

  • user.info.basic: shows the connected account's display name and avatar so the user can confirm the destination account.
  • video.upload: sends a video to the user's TikTok inbox as a draft for editing in the TikTok app.
  • video.publish: directly posts a video only after the user reviews the caption, privacy level, interaction settings and content disclosure, and explicitly clicks "Post".

The tool never posts without the user's explicit action and does not collect other users' content or personal data. Users can disconnect at any time.
