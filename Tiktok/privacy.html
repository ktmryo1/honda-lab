プライバシーポリシー

制定日：2026年10月13日

Honda Lab（以下「運営者」）は、投稿管理ツール「AffiliateAutoPost」と各SNSとの連携機能（以下「本サービス」）、および本サイトにおける情報の取り扱いを、以下のとおり定めます。

1. 取得する情報

連携先取得する情報
TikTokOpen ID、表示名、プロフィール画像（user.info.basic）、アクセストークン、リフレッシュトークン、投稿のID・処理状態
Instagram・Facebook・Threads（Meta）アカウントID、ユーザー名、Facebookページの名前とID、アクセストークン、投稿ID
YouTube（Google）チャンネルID、チャンネル名、アクセストークン、リフレッシュトークン、アップロードした動画のID
楽天ウェブサービス等商品の公開情報（商品名、価格、画像URL、商品ページURL）

本サービスは、パスワード、メッセージ、フォロワーの個人情報、他人の投稿内容を取得しません。

2. 利用目的

  • 連携したアカウントを画面に表示し、投稿先を確認するため
  • 利用者が指示した動画・画像・文章を、連携したアカウントへ投稿・予約投稿するため
  • 投稿の処理状態を確認し、エラーを通知するため

3. 保存場所と安全管理

アクセストークン等の認証情報は、利用者のパソコン上のデータベースに暗号化して保存します。運営者のサーバーや第三者のサーバーには送信しません。本サービスは、各プラットフォームのAPIとの通信をHTTPSで行います。

4. 第三者への提供

取得した情報は、法令に基づく場合を除き、第三者に提供・販売しません。投稿する際は、投稿先のプラットフォーム（TikTok、Meta、Google）へ、投稿に必要な情報を送信します。

5. 保存期間と削除

  • 認証情報は、連携を解除した時点で削除します。
  • 投稿の履歴は、ツールの動作確認のために保存し、利用者がいつでも削除できます。
  • データ削除の方法は、データ削除の手順をご覧ください。

6. 連携の解除方法

  • TikTok：アプリの「設定とプライバシー」→「セキュリティと権限」→「アプリと権限」→「管理」から解除できます。
  • Instagram・Facebook・Threads：各アプリの設定にある「ウェブサイトとアプリ」または「アプリとウェブサイト」から解除できます。
  • Google（YouTube）：Googleアカウントのサードパーティ接続ページから解除できます。

7. YouTube API サービスについて

本サービスは YouTube API サービスを使用しています。YouTube連携を利用する場合は、YouTube 利用規約およびGoogle プライバシーポリシーに同意したものとみなされます。

8. 本サイトについて

本サイトはGitHub Pagesで公開しています。本サイト自体はCookieやアクセス解析ツールを使用していません。ただし、GitHubはセキュリティのためにアクセスログを記録する場合があります。また、本サイトに掲載したアフィリエイトリンク先では、販売事業者やアフィリエイトサービスが成果の計測のためにCookieを使用することがあります。

9. ポリシーの変更

本ポリシーを変更する場合は、本ページでお知らせします。

Privacy Policy

Effective date: October 13, 2026

This policy explains how Honda Lab (the "Operator") handles information in "AffiliateAutoPost" and its social media integrations (the "Service"), and on this website.

Information we collect

  • TikTok: Open ID, display name and avatar (user.info.basic), access and refresh tokens, and the IDs and status of posts created through the Service.
  • Meta (Instagram, Facebook, Threads): account ID, username, Facebook Page name and ID, access tokens, and post IDs.
  • YouTube (Google): channel ID and name, access and refresh tokens, and IDs of uploaded videos.
  • Rakuten Web Service, etc.: public product information (name, price, image URL, product page URL).

We do not collect passwords, direct messages, followers' personal data, or other users' content.

How we use it

Only to display the connected account, to upload or publish content the user explicitly instructs the Service to post, and to show posting status and errors.

Storage and security

Credentials are stored encrypted in a local database on the user's own computer and are never sent to the Operator's or any third party's servers. Communication with platform APIs uses HTTPS.

Sharing

We do not sell or share information with third parties except as required by law. Content is sent only to the platform the user chooses to post to.

Retention and deletion

Credentials are deleted when the user disconnects the account. Post history can be deleted by the user at any time. See Data Deletion Instructions. You can also revoke access from TikTok ("Settings and privacy" → "Security and permissions" → "Apps and services permissions"), Meta app settings ("Apps and websites"), or Google Account permissions.

YouTube API Services

The Service uses YouTube API Services. By using the YouTube integration you agree to the YouTube Terms of Service and the Google Privacy Policy.

This website

This site is hosted on GitHub Pages and does not use cookies or analytics itself. Affiliate link destinations may use cookies for conversion tracking.
